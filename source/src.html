    Sauvegarde des données

    Vos données (fiches, visites, récurrences, notes) sont enregistrées uniquement dans ce navigateur, sur cet appareil. Exportez une sauvegarde régulièrement, et utilisez-la pour transférer vos données vers un autre appareil ou la clé USB.

    Synchroniser avec un autre appareil

    Fusionne les données d’un autre appareil (téléphone, clé USB, version web) avec celles-ci, sans rien écraser : les visites sont réunies et la saisie la plus récente l’emporte. Ensuite, renvoyez le fichier synchronisé vers l’autre appareil.

    Fichier de données (clé USB)

    Avec Chrome ou Edge, reliez le CRM à un fichier sur votre clé USB : chaque modification y est enregistrée automatiquement, et vous retrouvez vos données sur n’importe quel ordinateur en ouvrant ce fichier.
